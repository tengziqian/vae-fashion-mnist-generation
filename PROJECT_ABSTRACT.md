# Project Abstract

Our project, **Variational Autoencoders for Image Generation on Fashion-MNIST**, focuses on building and analyzing a generative deep learning model that can learn a meaningful latent representation of clothing images and use that representation to generate new samples. Image generation is an important problem in machine learning because it requires a model to go beyond classification and learn the underlying structure of a data distribution. Instead of only predicting a label, the model must understand visual patterns such as shape, texture, and class-level variation well enough to create new examples. We chose Fashion-MNIST as our dataset because it is simple enough to support efficient experimentation, but more visually diverse than handwritten digit datasets. The dataset contains grayscale images from ten clothing categories, including shirts, coats, shoes, bags, and trousers, which makes it a useful benchmark for studying generative image models.

The main method we plan to use is a Variational Autoencoder (VAE). A VAE has two major components: an encoder and a decoder. The encoder maps each input image into a probability distribution in a lower-dimensional latent space, usually represented by a mean vector and a variance vector. The decoder then samples from this latent distribution and tries to reconstruct the original image. During training, the model is optimized with a loss function that combines reconstruction quality with a KL divergence term. The reconstruction term encourages the generated image to match the input, while the KL divergence term encourages the latent space to remain smooth and close to a standard normal distribution. This structure makes VAEs especially useful for image generation because we can sample random latent vectors and decode them into new images.

For Milestone 1, our goal is to define the problem, prepare the data pipeline, and establish a baseline solution. Our baseline will be a convolutional VAE trained on Fashion-MNIST images. We will evaluate the model qualitatively by comparing original images, reconstructed images, and randomly generated samples. We also plan to track training losses to understand whether the model is learning stable representations. For later milestones, we will improve the baseline by experimenting with latent dimensionality, network depth, and possible beta-VAE loss weighting. We may also compare different generated sample grids to analyze which clothing categories are easier or harder for the model to represent. By the end of the project, we expect to have a working image generation system and a clearer understanding of how VAEs balance reconstruction accuracy, latent space regularization, and sample quality.
